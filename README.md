# 🤖 بوت الفواصل والرياكشن التلقائي (Discord Reaction & Separator Bot)

بوت احترافي لديسكورد، مبني من الصفر بأحدث إصدار من `discord.js v14`. يقوم بالتفاعل التلقائي على الرسائل برياكشنات مخصصة، وإرسال فواصل (صور متحركة GIF أو صور ثابتة) بعد كل رسالة أو بعد عدد محدد من الرسائل.

---

## ✨ المميزات الرئيسية
- **إرسال الفواصل تلقائياً**: يرسل صورة أو GIF الفاصل بعد كل رسالة لترتيب الرومات (تقييمات، إثباتات، شوب، صور...).
- **رياكشنات متعددة**: يمكنك تحديد إيموجي واحد أو عدة إيموجيات لكل روم (عادية مثل `⭐` أو إيموجيات سيرفر خاصة `<:emoji:123>`).
- **تحكم بمعدل الفاصل (Interval)**: إرسال الفاصل بعد كل رسالة (`1`)، أو كل رسالتين، أو 5 رسائل، حسب رغبتك.
- **جاهز للعمل على Railway 24/7**: يحتوي على خادم ويب مدمج (Port 3000) لمنع توقف الخدمة، ونظام حماية كامل ضد الانهيار (Anti-Crash).
- **أوامر سلاش تفاعلية**:
  - `/test-separator`: لتجربة ظهور الفاصل في أي روم والتأكد من الصلاحيات.
  - `/stats`: لعرض إحصائيات البوت وعدد الفواصل والرياكشنات المرسلة.
  - `/ping`: لمعرفة سرعة استجابة البوت.
- **طابور زمني آمن (Queue System)**: معالجة الرسائل بالترتيب دون التعرض لباند أو تقييد ديسكورد (Rate Limit 429).

---

## 🚀 التشغيل السريع محلياً

1. تأكد من تثبيت [Node.js](https://nodejs.org) (إصدار 18 أو أحدث).
2. افتح موجه الأوامر داخل مجلد البوت واكتب:
   ```bash
   npm install
   npm start
   ```

---

## ☁️ الرفع والتشغيل على Railway

1. ارفع مجلد المشروع إلى مستودع **GitHub**.
2. في موقع **[Railway](https://railway.com)**:
   - أنشئ مشروعاً جديداً **New Project** ➔ **Deploy from GitHub repo**.
   - اختر المستودع الخاص بك.
3. توجه إلى تبويب **Variables** في خدمة Railway، وأضف المتغيرات التالية:

| المتغير | الوصف | مثال |
| :--- | :--- | :--- |
| `DISCORD_TOKEN` | توكن البوت | `MTE...` |
| `REVIEW_CHANNEL_ID` | آيدي روم التقييمات | `123456789012345678` |
| `REVIEW_EMOJIS` | إيموجي التقييمات | `⭐` أو `⭐,❤️` |
| `PROOFS_CHANNEL_ID` | آيدي روم الإثباتات | `123456789012345678` |
| `PROOFS_EMOJIS` | إيموجي الإثباتات | `✅` |
| `EXTRA_CHANNELS` | آيديات رومات إضافية (مفصولة بفاصلة) | `111...,222...` |
| `EXTRA_EMOJIS` | إيموجيات الرومات الإضافية | `🔥,❤️` |
| `SEPARATOR_FILE` | اسم ملف الفاصل | `separator.gif` |
| `SEPARATOR_INTERVAL` | تكرار الفاصل (1 = بعد كل رسالة) | `1` |
| `PORT` | منفذ السيرفر المدمج | `3000` |

---

## ⚙️ صلاحيات الديسكورد المطلوبة

1. من موقع **[Discord Developer Portal](https://discord.com/developers/applications)**:
   - اذهب إلى **Bot** ➔ فعّل خيار **Message Content Intent**.
2. في سيرفر الديسكورد:
   - امنح البوت الصلاحيات التالية في الرومات المستهدفة:
     - `View Channel` (رؤية القناة)
     - `Send Messages` (إرسال الرسائل)
     - `Attach Files` (إرفاق الملفات - مهم جداً لإرسال الفاصل)
     - `Add Reactions` (إضافة الرياكشنات)
     - `Read Message History` (قراءة سجل الرسائل)
